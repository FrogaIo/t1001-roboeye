# RoboEye

RoboEye — локальная система компьютерного зрения для навигации робота. Телефон
работает как беспроводная камера, а Mac выполняет детекцию объектов, принимает
решение `GO`/`STOP` и строит безопасную траекторию. Обработка выполняется в
локальной сети без облачного сервера.

## Возможности

- живое видео на телефоне без задержки сетевого round trip;
- передача JPEG-кадров на Mac по защищённому WebSocket примерно 3 раза в секунду;
- YOLO-World-детекция людей, стульев, столов, коробок, палет, погрузчиков,
  тележек и контейнеров;
- дополнительные zero-shot-описания для цветных и брендированных коробок;
- перспективная проезжая зона с секторами `LEFT`, `CENTER`, `RIGHT`;
- динамическая геометрия зоны по наклону телефона;
- маршруты `STRAIGHT`, `LEFT`, `RIGHT` и `BLOCKED`;
- безопасное решение `STOP` без дребезга;
- отдельная панель оператора на Mac с видео, диагностикой и журналом событий;
- локальные снимки инцидентов при переходе в `STOP`.

## Архитектура

```text
Телефон
  camera + motion sensor
          │ JPEG + pitch, WSS
          ▼
Mac / FastAPI ──► YOLO-World ──► GO/STOP + route
     │                                  │
     ├──► /monitor                      └──► JSON overlay на телефон
     └──► logs/ + incidents/
```

Телефон показывает исходное видео непосредственно через `getUserMedia`.
Полученные от Mac рамки и траектория рисуются поверх видео на `canvas`, поэтому
сам поток остаётся плавным. Новый кадр не отправляется до получения результата
предыдущего — очередь и растущая задержка не накапливаются.

## Требования

- macOS с Python 3.11–3.13;
- телефон и Mac в одной Wi-Fi сети;
- OpenSSL для локального сертификата;
- Safari или Chrome с доступом к камере и датчику движения;
- модель `yolov8s-worldv2.pt` в корне проекта.

Python 3.14 пока выводит предупреждение PyTorch о `torch.jit`, поэтому для
демонстрации предпочтительнее Python 3.12 или 3.13.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

При отсутствии весов их можно загрузить через Ultralytics:

```bash
python -c "from ultralytics import YOLOWorld; YOLOWorld('yolov8s-worldv2.pt')"
```

## Настройка локального HTTPS

Мобильный браузер разрешает камеру и датчик движения только в безопасном
контексте. Сначала узнайте адрес Mac в локальной сети:

```bash
ipconfig getifaddr en0
```

Если Wi-Fi использует другой интерфейс, найдите адрес через `ifconfig`. Затем
создайте сертификат, подставив свой IP:

```bash
chmod +x scripts/create-local-cert.sh
./scripts/create-local-cert.sh 192.168.1.42
```

Передайте `certs/roboeye-ca.crt` на телефон. На iPhone:

1. Установите профиль в «Настройки → Основные → VPN и управление устройством».
2. Включите полное доверие в «Настройки → Основные → Об этом устройстве →
   Доверие сертификатам».

После хакатона профиль `RoboEye Local CA` можно удалить.

## Запуск

```bash
source venv/bin/activate
uvicorn app:app --host 0.0.0.0 --port 8443 \
  --ssl-keyfile certs/server.key \
  --ssl-certfile certs/server.crt
```

Откройте:

- на телефоне — `https://<IP-Mac>:8443`;
- на Mac — `https://<IP-Mac>:8443/monitor`.

На телефоне нажмите «Включить камеру» и разрешите доступ к камере и движению.
Если доступ к датчику отклонён или датчика нет, система продолжит работать с
профилем наклона по умолчанию.

## Логика навигации

Проезжая зона занимает примерно нижнюю треть кадра. По вектору гравитации
телефон оценивает угол камеры, а Mac динамически меняет высоту и степень
схождения трапеции. Геометрия на серверном изображении и телефонном overlay
одинакова.

Сектор объекта определяется по нижней центральной точке его рамки на текущей
глубине трапеции. Предмет за пределами проезжей зоны не блокирует маршрут.
Близкий объект в центральном секторе немедленно включает `STOP`; возврат в `GO`
происходит только после трёх чистых кадров подряд.

Тёмный кадр переводит систему в `STOP` с причиной `CAMERA DARK`. Пустой или
повреждённый JPEG отклоняется без остановки сервера.

## Конфигурация и данные

- `config.py` — классы, пороги и параметры перспективы;
- `detector.py` — детекция, проекция, решение и отрисовка;
- `app.py` — HTTP/WebSocket-сервер;
- `static/` — интерфейсы телефона и Mac;
- `journal.py` — журнал переходов и снимки инцидентов.

Рабочие данные не попадают в Git:

- `logs/events.jsonl` — переходы `GO`/`STOP`;
- `incidents/*.jpg` — обработанные кадры при `STOP`;
- `certs/` — локальные ключи и сертификаты;
- `*.pt` — веса моделей.

## Быстрая диагностика

- Камера не открывается: проверьте HTTPS, доверие сертификату и разрешение
  браузера.
- Телефон не подключается: убедитесь, что устройства находятся в одной сети и
  порт `8443` доступен в macOS Firewall.
- Старая версия интерфейса: перезапустите сервер и полностью обновите вкладку на
  телефоне.
- Сетка не меняется: разрешите доступ к движению; текущий угол отображается на
  панели Mac.
